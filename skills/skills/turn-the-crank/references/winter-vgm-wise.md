# Winter/snow VGM crank notes — David Wise reframe

Use this when a crank asks for a wintery/snowy VGM theme, especially if the first pass drifts into generic orchestral fog.

## Durable lessons

- Preserve a hook the user likes. Reframe harmony/instrumentation/texture around it instead of rewriting the melody just to hit a style target.
- For David Wise cold-weather DNA, the arpeggio is often the atmosphere: use a continuous icy pulse/celeste/flute/mallet pattern as the snow-globe engine, not just a decorative top layer.
- Avoid over-literal snow. Pink/noise beds can quickly read as static and flatten the mix; keep them very low and let pitch material carry the cold.
- Prefer one continuous hummable lead phrase (`.slow(8)` or equivalent long-line treatment) over bracket-spliced phrase tiles like `][` when the brief is a timeless VGM theme. Phrase tiling can make a melody feel assembled rather than inevitable.
- Cold VGM harmony can be magical without becoming Soule-style minor string fog: maj7/dominant chromatic color and warm resolution can imply ice, aurora, and cave-hearth contrast.
- Be honest about status: parse/render/metrics can make a listen-pass candidate, but do not call a crank shipped unless the exact final files have the full proof loop and the musical judgment is satisfying.

## Snowwatch-style reference frame

A useful David Wise winter frame discovered in session:

- Lead references: `Ice in a Snow Bound Land` for icy chromatic maj7/dominant color; `Northern Hemispheres` for cold DKC atmosphere.
- Example harmonic color: `C#maj7 → C7 → D#maj7 → C7 → Bbmaj7 → Gm7 → Bbmaj7 → Am7`.
- Section arc language that worked for snowy VGM: first snowfall → distant ice → snow-globe theme → northern atmosphere → aurora bloom → cave/hearth contrast → north-star melt/resolution.

Treat this as a reusable pattern, not a fixed template; the hook still comes first.
